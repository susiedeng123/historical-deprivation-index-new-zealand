This repository provides a historical deprivation index in New Zealand in 1981, 1986, 1991.
1. The index is comparable across the three time points
2. The index was developed at Area Unit 2006 level
3. The index was developed from two indicators: unemployment and non-homeownership
4. More details about how this index was developed please find: https://population.org.nz/wp-content/uploads/2024/10/NZPR-VOL-50_Deng-et-al_.pdf
5. To use this index, please cite： Deng, B., Campbell, M., McLeod, G., Boden, J., Marek, L., Sabel, C. E., Norman, P., & Hobbs, M. (2024). Construction of a consistent historic time-series area-level deprivation metric for Aotearoa New Zealand.
